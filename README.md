# WiFi সময় ট্র্যাকার

আপনার মোবাইল ২৪ ঘন্টার মধ্যে কত সময় WiFi এর সাথে সংযুক্ত ছিল তা দেখানোর জন্য একটি Android অ্যাপ — অনেকটা **Digital Wellbeing** স্টাইলের UI-তে। দৈনিক, সাপ্তাহিক, মাসিক, বাৎসরিক এবং সর্বমোট (সব সময়ের) হিসাব দেখা যায়।

## কীভাবে কাজ করে

- একটি ব্যাকগ্রাউন্ড ফোরগ্রাউন্ড সার্ভিস (`WifiMonitorService`) সবসময় চলে এবং `ConnectivityManager` দিয়ে WiFi সংযোগ/বিচ্ছিন্ন হওয়ার মুহূর্ত ধরে রাখে।
- প্রতিটি "সংযুক্ত থাকার সময়" একটি সেশন হিসেবে ফোনের লোকাল ডাটাবেজে (Room) সংরক্ষিত হয় — কোনো ডেটা ইন্টারনেটে পাঠানো হয় না, সব কিছু আপনার ফোনেই থাকে।
- দিনের হিসাব ব্যবহারকারীর চাহিদা অনুযায়ী রাত ১২:০০:০১ সেকেন্ড থেকে পরের রাত ১২:০০:০০ পর্যন্ত ধরা হয়েছে (`StatsRepository.dayBounds`)।
- অ্যাপ চালু করলে দৈনিক/সাপ্তাহিক/মাসিক/বাৎসরিক/সবগুলো ট্যাবে সুন্দর রিং প্রোগ্রেস ও বার চার্টে হিসাব দেখা যায়।

## GitHub Actions দিয়ে APK বিল্ড করা

`.github/workflows/build.yml` ওয়ার্কফ্লোটি প্রতিটি push এ (main ব্রাঞ্চে) অথবা ম্যানুয়ালি (`workflow_dispatch`) চালিয়ে একটি ডিবাগ APK তৈরি করে।

ধাপগুলো:
1. এই পুরো ফোল্ডারটি একটি নতুন GitHub রিপোজিটরিতে push করুন।
2. GitHub রিপোর **Actions** ট্যাবে যান, "Android Build" ওয়ার্কফ্লো সিলেক্ট করে **Run workflow** চাপুন (অথবা এমনিতেই push করলে অটো চলবে)।
3. বিল্ড শেষ হলে "Artifacts" সেকশনে `wifi-tracker-debug-apk` নামে APK ডাউনলোড করতে পারবেন।
4. APK ফাইলটি ফোনে ইনস্টল করুন (Unknown Sources অনুমতি লাগতে পারে)।

## লোকালি বিল্ড করতে চাইলে

Android Studio (Hedgehog বা তার পরের ভার্সন) দিয়ে এই ফোল্ডারটি খুলুন। Studio নিজে থেকেই `local.properties` তৈরি করে SDK path বসিয়ে দেবে। এরপর Run চাপলেই ইনস্টল হয়ে যাবে।

## প্রয়োজনীয় পারমিশন

- **Notifications** (Android 13+): ব্যাকগ্রাউন্ড সার্ভিসের স্ট্যাটাস নোটিফিকেশনের জন্য।
- অ্যাপটি প্রথমবার চালু করার পর, ব্যাটারি অপ্টিমাইজেশন থেকে অ্যাপটিকে বাদ দিয়ে রাখলে (Settings → Apps → WiFi সময় → Battery → Unrestricted) ট্র্যাকিং আরও নির্ভরযোগ্য হবে, কারণ Android মাঝেমধ্যে ব্যাকগ্রাউন্ড সার্ভিস বন্ধ করে দেওয়ার চেষ্টা করে।

## প্রজেক্ট গঠন

```
app/src/main/java/com/wifitracker/app/
  data/               → Room entity, DAO, Database, StatsRepository (হিসাব-নিকাশের মূল লজিক)
  service/            → WifiMonitorService (ব্যাকগ্রাউন্ড ট্র্যাকিং)
  receiver/           → BootReceiver (রিবুটের পর সার্ভিস আবার চালু করে)
  ui/                 → MainViewModel, HomeScreen, থিম ও কম্পোনেন্ট (Jetpack Compose)
```

## ভবিষ্যতে যোগ করা যেতে পারে

- ডেটা এক্সপোর্ট (CSV)
- বাংলা/ইংরেজি ভাষা টগল
